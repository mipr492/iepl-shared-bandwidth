## IEPL 共享带宽到底指什么

先厘清概念，避免后面被话术带跑。

**IEPL** 全称 International Ethernet Private Line，是基于 L2 以太网的国际专线。它和 IPLC（International Private Leased Circuit，物理层专线）都属于 "拉一根专用通道"，差别主要在协议层级：IEPL 用以太网封装，IPLC 是端到端物理专线。两者延迟、稳定度在中小业务面前差距不大，IEPL 通常更便宜一些，也是 MKCloud 广港线主推的技术。

**共享带宽** 是与 "独享带宽" 相对应的计费方式。共享带宽给出的是一个 **峰值**，比如 200Mbps 或 300Mbps，含义是同一资源池下能达到的上限速率，并不保证任何时刻都能跑满；独享带宽则是固定的速率配额，写多少就跑多少，不被他人挤占。Mkcloud 知识库也明确说明：共享和独享都是每台机器分配 1 个独立入口 IP + 1 个独立出口 IP，"共享/独享"的差别只在带宽模式，不影响 IP 是否独立。

把这三点拼起来：**IEPL 共享带宽 = 用以太网专线的方式连到境外节点，按峰值带宽计费、月流量设上限**。理解到这一层，后面的套餐差异、适用场景、避坑要点就都能围绕 "峰值 vs 持续速率"、"按流量计费 vs 不限流量" 这两根主线展开。

如果你的业务是 **集中时段上传、下载素材、跑后台任务、跨境办公、间歇性传输**，共享带宽峰值往往足够，并且能省下一大笔。MKCloud 广港共享入门 228 元/月（500GB 流量、150Mbps 峰值），跨境电商中小卖家的日常传图、传视频就能扛住。

## 三个最容易踩的坑

### 坑一：把 "共享峰值" 当成 "保证速率"

很多商家写 "200Mbps" 却不写 "峰值" 两个字，让用户以为是固定速率。MKCloud 在知识库和套餐说明里都明确标了 "共享带宽为峰值，不保证持续跑满"，这是行业惯例，不算坑，只是要留个心眼。如果你的业务是 7×24 推流、转码、持续大文件同步，应该用独享不限流量一类，而不是按峰值买流量计费套餐。

### 坑二：拿 "MB 换算" 直接比价

mkcloud 测试数据里写每 GB 流量折合 ¥0.7–0.8，但厂商对外宣传时往往把 "500GB 套餐 228 元" 拆成 "每月 0.46 元/GB" 显得更便宜。算总账的时候要拉到一个月实际消耗的体积，按照上行 + 下行双计去算，不要拿 "套餐容量" 直接除以 "单价"。

### 坑三：忽略实名制与白名单限制

IEPL / IPLC 都需要国内手机号 + 身份证号 + 姓名一致性验证，这是合规跨境业务的硬门槛，不能用海外身份或借用他人信息代购。同时 Mkcloud 会把入口 IP 锁定一个省份白名单，多省份办公团队需要分别开通，避免被迫切换。

## 常见问题

**Q1：IEPL 共享带宽能不能解锁 Netflix / ChatGPT？**
MKCloud 是服务器出口 IP，没有承诺原生、住宅或流媒体解锁属性，也没有承诺账号平台能豁免风控。不要把 "解锁" 当作购买 IEPL 的目的。

**Q2：共享带宽和独享带宽哪个对账号安全更友好？**
两者在 MKCloud 都是单台 VPS 配独立入口 + 独立出口 IP，"共享 vs 独享" 是带宽模式差异，不决定平台是否认可。

**Q3：买完之后能不能降级？**
套餐升降级需要提交工单处理。降级到更低价格套餐时，差价不退；具体能否迁移以工单回复为准。

**Q4：新客 228 元和 198 元是真的吗？**
历史活动里出现过低至 198 元（双旦 9 折叠加）的价格，也有新客专享 236 元的限时套餐。目前 Mkcloud 知识库对 "活动优惠码仅在活动期内有效" 写得很清楚，下单前要在活动页核对截止时间，不要直接套用历史价。

**Q5：入口只能绑定一个省份，会不会影响多地办公？**
是的，MKCloud 限制入口 IP 白名单为单一省份。多省份办公需要分别开通对应套餐，或选择不限省份的 IX 上云互联方案。
